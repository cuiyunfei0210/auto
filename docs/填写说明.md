# 填写说明与提交清单

## 一、词义区分

实务中“限高”指人民法院对被执行人采取的**限制消费措施**。

| 说法 | 谁提出 | 目的 |
| --- | --- | --- |
| 申请限制消费 / 申请限高 | 申请执行人 | 第一次采取限高 |
| **申请恢复限高** | 申请执行人 | 限高曾解除或暂停，现重新采取 |
| 申请恢复执行 | 申请执行人 | 中止、终本或和解后重新启动强制执行 |
| 申请解除限高 | 被执行人或经同意的申请执行人 | 取消限制消费令 |
| 因生活/经营必需申请消费 | 被执行人 | 不解除限高，只批准某一次消费 |

纳入失信被执行人名单与限高不是同一措施。已纳入失信名单的，法院依法应当同时限高；限高可以单独采取。需要重新纳入失信名单的，在申请事项中单列一项。

## 二、申请书怎么填

1. 标题居中，用“恢复限制消费措施申请书”或“恢复执行申请书”。
2. 当事人按执行案件列明：申请执行人、被执行人。单位写全称、统一社会信用代码、住所、法定代表人；自然人写姓名、性别、民族、出生日期、身份证号、住址、电话。
3. 执行案号、原审案号、执行法官（如已知）务必核对无误，可在中国执行信息公开网或裁判文书、执行裁定书上抄录。
4. 申请事项先写请求，再写事实与理由，不要把证据清单写进请求主文。
5. 金额用汉字大写加阿拉伯数字，例如：人民币壹拾万元整（¥100,000.00）。
6. 落款与申请人名称一致；委托律师提交的，另附授权委托书和律师证复印件。
7. 打印后在落款处签字或盖章，骑缝按法院要求处理。

## 三、被执行人是单位时

除对被执行人单位恢复限高外，可一并列明对其**法定代表人、主要负责人、影响债务履行的直接责任人员、实际控制人**恢复限制消费措施，并写明姓名、职务、身份证号。

## 四、法律依据（填写时按需引用）

- 《中华人民共和国民事诉讼法》第二百四十一条（执行和解后恢复原生效法律文书的执行）
- 《中华人民共和国民事诉讼法》第二百五十条（申请执行期间为二年）
- 《最高人民法院关于执行和解若干问题的规定》第九条、第十条、第十七条
- 《最高人民法院关于限制被执行人高消费及有关消费的若干规定》第一条、第二条、第四条、第九条
- 《最高人民法院关于公布失信被执行人名单信息的若干规定》相关条款（需要恢复纳入失信名单时引用）
- 《最高人民法院关于严格规范终结本次执行程序的规定（试行）》关于终本后申请恢复执行的规定（终本案件引用）

条文序号如遇修法，以现行有效文本为准。

## 五、建议提交的材料

**一般应附：**

- 申请书原件（按法院要求的份数）
- 申请人身份证明（身份证 / 营业执照、法定代表人身份证明）
- 授权委托书及代理人身份证明（如有）
- 原生效法律文书
- 执行立案受理通知书或执行裁定书（含案号）
- 此前采取、暂停或解除限高的裁定、决定、通知（如有）

**按情形增附：**

| 情形 | 增附材料 |
| --- | --- |
| 和解后违约 | 执行和解协议、付款凭证、催告记录、尚未履行金额明细 |
| 终本后再申请 | 终结本次执行程序裁定书、新财产线索及证据 |
| 中止后再申请 | 中止执行裁定书、中止情形消失的证据 |
| 同时申请纳入失信 | 符合纳入情形的说明及证据 |
| 被执行人为单位 | 国家企业信用信息公示材料、法定代表人/实际控制人身份信息 |

证据逐项编号，与申请书中的“证据目录”对应。

## 六、怎么交到法院

- 执行法院诉讼服务中心或执行事务中心窗口
- 人民法院在线服务、律师服务平台、地方法院执行网络系统
- 邮寄至执行法院（保留寄递凭证）

部分法院要求通过执行案承办法官或执行指挥中心转交。提交后可要求出具收件回执，并记下承办人、联系电话。

## 七、常见卡点

1. **超期**：因不履行和解协议申请恢复执行的，期间一般自和解协议约定履行期间的最后一日起算，适用二年申请执行期间。不要拖到临期才交。
2. **请求范围**：恢复执行针对原判决、调解书、裁定确定的给付内容；和解中已履行部分必须扣除。
3. **择一行使**：被执行人不履行和解协议的，申请执行人可以申请恢复原生效文书执行，也可以就和解协议另行起诉，两条路径不要同时推进。
4. **限高不是终本的替代**：没有财产线索时，限高和失信仍可促使履行，但应同时继续查明财产。
5. **已履行完毕**：义务全部履行后，法院应当解除限高，此时应提交解除申请而不是恢复申请。
