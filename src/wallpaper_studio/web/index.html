壁纸工坊 二创 · 顺序上传

一次只开一个窗口。一个账号传完，再登录下一个。

任务

先准备图片，再按账号队列模拟网页上传。

空闲

本轮怎么跑

开始前必须选分类。选了动漫，二创生成的图和上传 CQwall 都按动漫，不会再用识图结果改分类。

0源图
0待二创
0账号

点「开始任务」会先重新扫描源目录。没选分类、缺账号、缺图片、二创没填 Key 都会弹窗说明。gpt-image-2 生图大约要几十秒，请看右侧日志。「待二创」是还没二创完的源图张数，每完成一张减 1。点「停止」会立刻出现在日志里；如果当前这张图正在请求中转站，会等这次请求结束再停，不会再做下一张。关窗口或点「退出程序」即可退出。

图片目录

          
          
          

          
留空则读取程序旁边的 data\source。请把 png/jpg/webp 放进「实际读取」的那个目录。同名同大小的图只二创一次，源目录里的「二创」子文件夹会跳过。跳过二创时直接上传源文件夹，不会再拷进输出目录。开始二创前会清空输出目录里的旧图，所以本轮二创张数会和源图一致。

        

      


      

        

          

            
账号队列

            
          

          
按列表顺序登录。CQwall 用邮箱当账号。当前账号的数量用完后，自动退出并登录下一个。每个账号应走不同出口，避免多个账号落在同一个 IP。填好后点右上角「保存设置」即可，不必先回到任务页。

出口 IP

          
目的是让每个账号使用不同的网络出口。不启用时代码仍可上传，但本机多个账号会表现为同一个 IP。

          
          
          
          
          

        

      


      

        

          
模拟网页上传

          
默认已对接 CQwall：首页邮箱登录弹层 → 创作中心上传。不限制图片宽高。账号页默认已填一个 CQwall 邮箱。

中转站 API

          
中转站固定 https://api.newxxt.top。生图用 gpt-image-2。写标题的模型从当前对话 Key 在中转站可用的列表里选，不再写死只能用 gpt-5.4-mini。

          
          
          
          
          
          
            
            
          
          
          
常用对话模型都可选。点「刷新模型」会尝试从中转站更新列表；列表刷新失败不影响你选中的模型，保存后写标题仍用这一项。

          
          
          
会按你填的二创提示词生成。分类以任务页本轮选择为准：选了军事就是军事，选了动漫就是动漫，识图不会改分类。上传 CQwall 也用这个分类。
