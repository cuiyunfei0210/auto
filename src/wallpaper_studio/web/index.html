壁纸工坊 二创 · 顺序上传

一次只开一个窗口。一个账号传完，再登录下一个。

任务

先准备图片，再按账号队列模拟网页上传。

空闲

本轮怎么跑

0源图
0待上传
0账号

运行日志


          

        

      


      

        

          
图片目录

          
          
          
留空则使用程序目录下的 data/source 和 data/output。跳过二创时，也会把源图拷到输出目录并可用 API 生成标题。

        

      


      

        

          

            
账号队列

            
          

          
按列表顺序登录。当前账号的「上传数量」用完后，自动退出并登录下一个账号。
