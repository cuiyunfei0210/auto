壁纸工坊 二创 · 顺序上传

一次只开一个窗口。一个账号传完，再登录下一个。

任务

先准备图片，再按账号队列模拟网页上传。

空闲

本轮怎么跑

0源图
0待二创
0账号

点「开始任务」会先重新扫描源目录。缺账号、缺图片、二创没填 Key 都会弹窗说明。二创走 xmapi 的 gpt-image-2 生图，大约要几十秒，请看右侧日志。「待二创」是还没二创完的源图张数，每完成一张减 1。

运行日志


          

        

      


      

        

          
图片目录

          
          
          

          
留空则读取程序旁边的 data\source。请把 png/jpg/webp 放进「实际读取」的那个目录，子文件夹里的图也会算。不要只放到桌面或 WallpaperStudio 根目录。拷好后回到「任务」页，源图数字过一两秒会自己更新。输出目录里会堆积历次二创结果；只想看本轮的话，可先清空 data\output。

        

      


      

        

          

            
账号队列

            
          

          
按列表顺序登录。CQwall 用邮箱当账号。当前账号的数量用完后，自动退出并登录下一个。每个账号应走不同出口，避免多个账号落在同一个 IP。

出口 IP

          
目的是让每个账号使用不同的网络出口。不启用时代码仍可上传，但本机多个账号会表现为同一个 IP。

          
          
          
          
          

        

      


      

        

          
模拟网页上传

          
默认已对接 CQwall：首页邮箱登录弹层 → 创作中心上传。不限制图片宽高。账号页默认已填一个 CQwall 邮箱。

二创提示词以你填的为准。电影级光影、atmospheric depth 这类词很容易出黄昏；想要别的时段请写「正午 / 阴天 / 夜晚 / 冷色」。gpt-image-2 原生只有 1024×1024、1536×1024、1024×1536。填 2K/4K/1920×1080 时，程序会先按最接近的档位出图，再放大到目标尺寸（不是模型直接出 4K）。留空提示词会用默认改图词。生图请填 https://xmapi.site（不要带 /v1）。
