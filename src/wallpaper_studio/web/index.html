壁纸工坊 二创 · 顺序上传

一次只开一个窗口。一个账号传完，再登录下一个。

任务

先准备图片，再按账号队列模拟网页上传。

空闲

本轮怎么跑

0源图
0待二创
0账号

点「开始任务」会先重新扫描源目录。缺账号、缺图片、二创没填 Key 都会弹窗说明。gpt-image-2 生图大约要几十秒，请看右侧日志。「待二创」是还没二创完的源图张数，每完成一张减 1。点「停止」会立刻出现在日志里；如果当前这张图正在请求中转站，会等这次请求结束再停，不会再做下一张。关窗口或点「退出程序」即可退出。

图片目录

          
          
          

          
留空则读取程序旁边的 data\source。请把 png/jpg/webp 放进「实际读取」的那个目录。同名同大小的图只二创一次，源目录里的「二创」子文件夹会跳过。跳过二创时直接上传源文件夹，不会再拷进输出目录。开始二创前会清空输出目录里的旧图，所以本轮二创张数会和源图一致。

        

      


      

        

          

            
账号队列

            
          

          
按列表顺序登录。CQwall 用邮箱当账号。当前账号的数量用完后，自动退出并登录下一个。每个账号应走不同出口，避免多个账号落在同一个 IP。

出口 IP

          
目的是让每个账号使用不同的网络出口。不启用时代码仍可上传，但本机多个账号会表现为同一个 IP。

          
          
          
          
          

        

      


      

        

          
模拟网页上传

          
默认已对接 CQwall：首页邮箱登录弹层 → 创作中心上传。不限制图片宽高。账号页默认已填一个 CQwall 邮箱。

OpenCode 配置里的 gpt-5.x 是对话模型，不能直接当生图模型。二创请走 gpt-image-2。newxxt 这组 Key 同时有 gpt-image-2 和 gpt-5.4-mini，可以生图也能根据图片写标题。aipixapi 这组 Key 只有 gpt-image-2，写标题会自动改走 newxxt。gpt-image-2 只能出 1024×1024 / 1536×1024 / 1024×1536，程序不再放大。二创提示词以你填的为准；电影级光影、atmospheric depth 很容易出黄昏，想要别的时段请写正午、阴天、夜晚或冷色。标题语言以「文件名提示词」为准，要英文就写 English title；程序不再强制中文。
