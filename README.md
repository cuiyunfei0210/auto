# 人民法院申请恢复限高模板

向执行法院提交的**恢复限制消费措施（限高）**申请书空白模板，按《最高人民法院关于限制被执行人高消费及有关消费的若干规定》（2015年修正）和现行《民事诉讼法》整理。

## 先选模板

| 情形 | 用哪一份 |
| --- | --- |
| 执行程序仍在进行，此前因和解、担保或同意而解除了限高，现需重新限高 | [`templates/01-恢复限制高消费申请书.md`](templates/01-恢复限制高消费申请书.md) |
| 和解后对方违约，或终本/中止后发现财产，需要**同时恢复执行和恢复限高**（最常见） | [`templates/02-恢复执行并恢复限高申请书.md`](templates/02-恢复执行并恢复限高申请书.md) |
| 实际要办的是**解除限高**（已履行完毕、提供担保、或申请执行人书面同意） | [`templates/03-解除限制高消费申请书.md`](templates/03-解除限制高消费申请书.md) |

填写方法和附件清单见 [`docs/填写说明.md`](docs/填写说明.md)。

## 使用注意

- 限高的正式名称是**限制消费措施 / 限制消费令**，申请书标题建议写全称，可在括号中注明“限高”。
- 恢复限高由**申请执行人**提出；被执行人申请的是解除或单次批准消费，不是“恢复限高”。
- 和解违约后申请恢复的是**原生效法律文书**，已付款应扣除；一般不能把和解协议里另加的违约金一并当作原判决来执行。
- 本仓库仅提供文书格式参考，不构成法律意见。具体案号、金额、期限以执行案卷和当地法院要求为准。
