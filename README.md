# 芽芽乐园

给小朋友用的小应用：听儿歌、看动画、读图画故事，还可以点小动物和玩木琴。

打开就是一页大按钮。内容都在应用里面，没有广告，也不会跳到别的网站。儿歌用音乐盒音色演奏传统曲子，歌词会跟着亮起来。动画和故事是原创的。

## 里面有什么

- **儿歌**：两只老虎、小星星、找朋友、小兔子乖乖、丢手绢、一起拔萝卜、划小船、小羊羔、伦敦桥、小芽芽、摇篮曲
- **动画**：小兔子找萝卜、海底泡泡（可以点）、小火车出发、雨过天晴
- **故事**：红气球、月亮船，可以一页一页翻，也可以读出来
- **点一点**：八种小动物的叫声，还有五音木琴
- **家长**：首页角落按「家长」，按住小太阳约两秒。可以调音量，也可以设 5、10 或 15 分钟后休息

## 在电脑上打开

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:5173

```bash
npm test
npm run build
npm run preview
```

## 放到平板上

用平板浏览器打开后，选「添加到主屏幕」或「安装应用」。它会像一个单独的 App 一样打开。

休息时间到了以后，画面会停在睡觉页。爸爸妈妈按住小太阳，就可以继续。
